# 语义双语字幕投影设计

## 目标

解决双语烧录字幕过长、被原始字幕 cue 边界切碎的问题。以下载目录的原始英文字幕为只读事实来源，在文章目录生成按中文完整句重组、且中英共用时间轴的字幕资产。实现采用 BaoCut 的“两阶段翻译 + 定向重对齐 + 交付质量门”模型，而不调用 BaoCut 或接入本地 ASR。

## 范围与边界

- 仅在 `--subtitle-bilingual srt|ass|burned|all` 时默认启用；`--no-subtitle-semantic` 选择文章侧的逐 cue 投影。
- `files/downloads/<videoId>/` 是只读输入；语义路径和逐 cue 回退都不得在其中新建、修改或删除字幕文件。
- 第一版不接入本地 ASR、字幕编辑器、动画或可保存的样式系统。
- 分组使用原始 cue 的连续范围作为唯一时间证据；没有安全的、cue 边界可表达的自然语义断点时，不得凭空拆出新时间窗。

## 产物契约

所有二创字幕资产位于 `files/articles/<videoId>/video/`：

```text
full.en.srt                    # 语义组英文；与 zh/bilingual 同一时间轴
full.zh.srt                    # 语义组中文
full.bilingual.srt             # 中文第一行、英文第二行
full.bilingual.semantic.json   # 阶段、来源、样式与质量指纹
full.bilingual-burned.mp4      # 仅通过交付质量门时存在
```

下载目录中的原始字幕保持字节不变。`full.bilingual.semantic.json` 必须标识 `kind: "semantic-bilingual"` 或 `kind: "cue-aligned-fallback"`，避免单语烧录把语义组字幕误当作下载侧逐 cue 产物。

## BaoCut 式两阶段模型

### 阶段一：完整句翻译与组装

连续读取原始英文 cue，LLM 返回完整自然中文句及其连续 cue 范围。每个组持久化 `groupId`、`sourceStartIndex`、`sourceEndIndex`、`sourceText`、`zhText`、`start`、`end`。英文按同一范围合并；全部原始 cue 必须恰好覆盖一次。

阶段一的组与文本是后续对齐的基准。未被阶段二选中的组必须保持文本和时间窗字节不变。

### 阶段二：仅定向重对齐 over-fit 组

使用真实烧录字体、视频尺寸和 80% 画面宽度测量阶段一 SRT。每组得到：

- `fit`：一行舒适显示，绝不重对齐；
- `aim`：接近目标长度，可保持原句；
- `hard`：超过两行或安全区，必须存在安全拆分，否则阻止烧录。

只把 `hard` 组及其稳定 `groupId` 送入阶段二。返回的替代子组必须只覆盖对应父组的连续 cue 范围；不得改写其他组、不得按普通逗号硬拆、不得在任一子组少于一秒时拆分。没有安全 cue 边界时保留该句并记录 `unsafe-layout`，不会伪造时间；对 `burned` / `all`，这会使交付质量门失败。

## 视觉与字体基线

- 底部安全区、80% 宽；译文（简体中文）在上、原文（英文）在下；两行间距 `0px`、分开背景。
- 720p 基准：译文 `30px`、原文 `16px`，均粗体、白色 `#FFFFFF`；译文黑描边 `#000000`、粗细 `8px`，原文无描边；两行均启用 `#404040` 阴影，100% 不透明度、距离 `0.08`、模糊 `0.10`、角度 `45°`。原文行高 `1.20`、左对齐。
- 字体链：`Lexend Deca → PingFang SC → Hiragino Sans GB → STHeiti`。实际命中的字体文件、720p 基准、渲染器版本、视频尺寸和宽度比例共同构成布局/烧录指纹。
- SRT 保留原标点；仅在最终渲染投影时将简体中文逗号和句号替换为空格。交付最多两行；视频默认变换保持 100% 缩放、0° 旋转、位置 `(0,0)`，不把视频画布模糊填充应用到字幕。

## 校验、回退与缓存

- 内容错误：非 JSON、空文本、非连续或重复覆盖、来源 SHA 不一致、无效/重叠/倒退时间、双语时间不一致。发生时生成文章侧 `cue-aligned-fallback` 并记录机器可读错误码。
- 展示错误：`hard` 宽度、超过两行、读取速度或安全布局不满足交付阈值。保留可审计的语义资产，但 `burned` / `all` 不输出 MP4。
- 缓存分层：阶段一键为原始 SRT SHA、模型和翻译规则版本；阶段二/烧录键为阶段一 SHA、实际字体链、渲染器版本、视频尺寸、80% 宽度及样式版本。仅布局变化时不得重翻译。
- 所有 SRT、manifest 和 MP4 均以临时文件完成校验后原子替换；缓存命中还必须检查对应文件存在且 SHA 匹配。

## 验证范围

- 多条碎英文 cue 合并为完整自然中文和共享时间块；未命中组字节不变。
- `fit` 不调用阶段二；只有 `hard` 的稳定 `groupId` 进入定向对齐；无安全边界的 hard 组不伪造时间。
- 字体缺失时按指定链回退，实际字体变化导致重新测量与重烧录。
- 内容错误生成文章侧逐 cue 回退；下载侧原始 SRT SHA 前后不变。
- 质量门拒绝带 `hard`/两行/CPS 阻断项的烧录，但保留语义 SRT 和明确报告。
